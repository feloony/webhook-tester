# Webhook Tester 🪝

A polished browser-based webhook payload inspector and request simulator for developing and debugging webhook-shaped data.

## ✨ Features

- Request method and path editor
- Headers editor
- JSON payload editor
- Payload validation and formatting
- Simulated request log
- Developer-friendly response inspection
- Responsive interface
- No account or runtime dependencies

## ⚠️ Current scope

This static version is an **offline request composer and inspector**. It does not expose a public internet webhook endpoint or receive external traffic.

A future server adapter can add real receiving endpoints while keeping the frontend independent.

## 🚀 Run

Open `index.html` in a modern browser or serve the folder with any static web server.

## 🤝 Contributing

Useful additions include real receiver adapters, request replay, exportable payloads, filters, search, and optional local history.
