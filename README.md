# Webhook Tester

A polished browser-based webhook payload inspector and request simulator.

## Features
- Webhook-style request composer
- Method, path and headers editor
- JSON payload editor
- Payload validation and formatted inspection
- Simulated request log
- Responsive developer UI
- No account or dependencies

## Important
This static version is an offline inspector/simulator. It does not expose a public internet webhook endpoint. A future server adapter can add real receiving endpoints while keeping this frontend.

## Run
Open `index.html` in a browser.
